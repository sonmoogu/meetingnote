# 03. Design

기술·디자인 결정 8개를 표 하나로 정리한다. 열은 선택 / 대안 / 근거 / 트레이드오프 4개로 고정한다.

| 항목 | 선택 | 대안 | 근거 | 트레이드오프 |
|---|---|---|---|---|
| 1) 백엔드 | FastAPI | Django, Express | Python 타입 힌트 기반 검증과 Swagger 문서가 자동으로 나온다. 작은 REST API 7개에 필요한 만큼만 쓴다. | Django 의 관리자 화면·인증 같은 기본 제공 기능은 없다. 필요하면 직접 붙여야 한다. |
| 2) 프론트 | Vanilla JS + Tailwind CDN<br>(`index.html` + `app.js` 2개 파일)<br>프론트는 백엔드가 같은 오리진에서 제공한다. `file://` 로 직접 열지 않는다. | React, Vue | 빌드 도구가 없고 파일이 2개뿐이라 유지보수 대상이 적다. 같은 오리진이라 CORS 설정이 필요 없다. | 화면이 커지면 DOM 갱신 코드가 늘어난다. 컴포넌트 재사용 기능이 없다. 서버를 띄워야 화면을 볼 수 있다. |
| 3) DB | SQLite (SQLAlchemy ORM, 추후 PostgreSQL 전환 고려) | PostgreSQL 즉시 도입 | 설치와 설정이 필요 없는 파일 DB 라 MVP 속도가 빠르다. ORM 을 쓰므로 DB 교체 때 바뀌는 코드가 적다. | 동시 쓰기에 약하다. PostgreSQL 전환 시 타입·AUTOINCREMENT 차이를 점검해야 한다. |
| 4) CSS | Tailwind 만 쓴다. styled-components 금지. | styled-components, 직접 작성한 CSS 파일 | 스타일 방식을 하나로 고정해 파일과 규칙이 늘어나지 않는다. | HTML 클래스 목록이 길어진다. CDN 방식이라 사용하지 않는 클래스를 걷어내는 최적화는 하지 않는다. |
| 5) 받아쓰기 | Gemini API (`gemini-3.1-flash-lite`)<br>키는 `.env` 로만 읽고, 저장소에 올리지 않는다. | Whisper 자체 구동, 브라우저 음성 인식 | 서버에 모델을 올리지 않고 API 호출 한 번으로 받아쓰기와 구분을 처리한다. | 외부 호출이라 네트워크·한도·비용 영향을 받는다. 실패하면 502 로 응답한다. |
| 6) 상태관리 | 모듈 변수 + DOM 직접 갱신 | Redux, Zustand 같은 상태 라이브러리 | 화면 4종 규모에서는 모듈 변수 몇 개로 충분하다. 의존성이 늘지 않는다. | 상태가 늘면 어디서 DOM 을 바꾸는지 추적하기 어렵다. 그 시점에 재검토한다. |
| 7) 디자인 시스템 | Mac OS UI 톤<br>화면 배치는 `docs/화면구성.pdf` 를 따르고 옮겨 적지 않는다.<br>화면 요소 이름(id)은 아래 id 표를 그대로 쓴다.<br>한 번 정하면 바꾸지 않고, 바꿔야 하면 사유를 먼저 적는다.<br><br>**id 표 (`화면구성.pdf` 5쪽)**<br>검색 입력: `q` · `from` · `to` (목록 화면 상단)<br>목록 칸: `cards` (카드 배치 구역)<br>넣기 폼: `title` · `metAt` · `attendees` (제목 · 일시 · 참석자)<br>파일 · 본문: `file` · `body` (녹취 파일과 받아쓴 본문)<br>버튼: `btnUp` · `btnSave` (받아쓰기 · 정리)<br>결과 세 칸: `result` (요약 · 결정사항 · 할 일)<br>상세 창: `modal` (카드를 누르면 뜨는 겹침 창)<br>제목 수정칸: `mTitle` (상세 창 안에서 제목을 고치는 칸)<br>할일표: `todoBody` (표의 본문 행) | Material, Ant | 둥근 모서리·부드러운 그림자·반투명 카드·시스템 폰트로 `01-product.md` 의 UI 톤을 따른다. id 를 고정하면 화면을 다시 만들어도 `app.js` 가 깨지지 않는다. | 외부 디자인 시스템이 주는 완성된 컴포넌트는 쓰지 못한다. id 를 바꾸려면 문서와 코드를 함께 고쳐야 한다. |
| 8) 테마 | 라이트/다크 토글, `localStorage` 에 저장, 초기값은 시스템 설정 | 라이트 고정, 서버에 저장 | 로그인 없이도 사용자별 선택이 유지된다. 처음 방문에도 OS 설정과 어긋나지 않는다. | 브라우저·기기가 바뀌면 선택이 이어지지 않는다. `localStorage` 가 막힌 환경에서는 시스템 설정을 따른다. |
