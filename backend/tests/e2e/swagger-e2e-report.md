## 확인한 것과 한계

- 확인한 것: Swagger 에서 7개 API 를 모두 실행할 수 있고, 상태 코드와 응답 형태가 `02-specs.md` 와 맞는다.
- 한계 1: 업로드 성공 경로(13번)는 Windows TTS 로 만든 **영어** 음성 파일로 확인했다. 한국어 녹취는 아직 확인하지 않았다.
- 한계 2: 노트 생성(1번)의 세 갈래 구분은 "세 칸이 모두 채워졌는가"만 봤다. 구분 내용이 `02-specs.md` 의 기준에 맞는지는 눈으로 확인하지 않았다.
- 한계 3: `from`/`to` 날짜 검색, 502(외부 호출 실패), 구분 실패 시 빈 값 저장은 이 실행에 포함하지 않았다. 이 항목들은 앞서 pytest 와 별도 확인으로 검증했다.
- 한계 4: `PUT` 은 요약·결정사항·할 일을 함께 보냈다. 보내지 않았을 때 기존 값이 유지되는지는 이 실행에서 보지 않았다.

## 남은 상태

- 테스트가 만든 노트는 14번에서 지웠다. 서버 DB 에는 남은 노트가 없다.
- `id` 는 AUTOINCREMENT 라서 다음 노트는 2번부터 시작한다.

## 재실행 방법

1. 서버를 포트 8000 에서 띄운다 (`backend/` 에서 `uvicorn app.main:app --port 8000`).
2. 프로젝트 밖의 빈 폴더에서 `npm i playwright` 를 실행한다. 프로젝트 의존성에는 넣지 않는다.
3. 같은 폴더에 `swagger.mjs` 를 복사해 `node swagger.mjs` 를 실행한다.
4. wav 업로드 케이스는 `%TEMP%\mn_sample.wav` 파일이 필요하다.
